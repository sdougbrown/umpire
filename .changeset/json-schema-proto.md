Scaffold the `@umpire/json-schema` package — a prototype of the JSON Schema composition profile. Adds `compileProfile()`, `compileSchemas()`, `CompiledProfile` with separate `check()`/`validateStructure()`/`evaluate()` APIs, and `filterStructuralIssues()` UI helper. Structural validation uses AJV 2020-12 and remains independent of Umpire availability evaluation.
